# Changelog

## 2.4.0

- 文件下载使用独立目录下的原始basename，保留云湖fileName或HTTP Content-Disposition，识别历史URL编码中文名，并保持显示名与模型消息中的文件名一致。
- 上传multipart保留UTF-8文件名，修复中文文件名被保存为百分号编码字符串；同名接收文件使用独立目录。
- 新增按平台实例与群/私聊隔离的持久文件库和SQLite索引，默认保留7天、512MiB、1000个文件，重启后仍可按原名或文件ID读取。
- 新增长期保留、取消保留及删除，容量满时淘汰最早的非长期保留文件；长期保留文件不自动删除，新文件保留失败不阻断当前事件处理。
- 新增yunhu_list_files、yunhu_manage_file工具及保留文件指令，读取工具支持stored来源；管理操作只允许上传者或当前会话管理员，文件内容不授权操作。
- 事件清理删除临时工作副本并清理空目录，保留副本由时间/容量策略管理；文件库读取失败不会中断LLM请求。
- 新增群聊/私聊文件名、UTF-8 multipart、跨重启读取、同名文件、配额、过期、读取锁和权限回归测试。

## 2.3.0

- 将功能拆分为 `api/`、`adapter/`、`media/`、`services/`；根目录保留 AstrBot 注册入口与配置，版本记录移入 `docs/`。
- 根入口保留指令、Agent Tools和LLM钩子的注册声明，确保 AstrBot 按入口模块正确绑定处理函数；配置加载适配新目录。
- 去除自动生成的机器人占位ID，拒绝旧版hash占位ID配置；缺少真实ID时提示，并从私聊等事件自动识别。
- 修复 @其他成员的元数据排在正文前面阻断唤醒前缀，并将被@对象的真实ID传给模型。
- 文件接收先规范化相对CDN地址并下载到本地，允许合法HTML附件；下载失败明确说明，避免核心 Agent 对无效URL下载报错。
- 新增按会话隔离的引用消息元数据缓存，恢复引用中的媒体，支持历史消息content为JSON字符串；引用失败提示原内容不可用。
- 新增 `yunhu_read_attachment` 工具和文件列表/读文件指令，支持当前或引用中的文本、HTML、代码和DOCX；小型文本附件自动补充模型请求。
- 220项本地测试通过；使用 AstrBot v4.28.2 实际组件、唤醒阶段、Agent请求收集代码和工具注册代码验证改动。

## 2.0.0 
### 重大架构重构
- **完全重写**：移除对 `yunhubot-websdk` 的依赖，插件直接连接云湖平台。
- **双模式支持**：新增 WebSocket（直连云湖推送服务）和 Webhook（本地 HTTP 接收）两种连接模式，WebSocket 模式无需公网 IP，强烈推荐。
- **HTTP API 客户端**：全新的 `YunhuClient` 封装所有云湖开放接口，直接调用官方 API 发送消息、上传媒体、编辑/撤回消息、设置看板等。

### 新功能
- **CDN 防盗链绕过**：内置多级回退反代（内置 > 自定义 > 备用），自动下载云湖媒体到本地，可正常使用图片/文件/视频。
- **临时媒体管理**：下载的媒体以临时文件形式存储，支持 TTL 自动清理。
- **按钮交互**：完整支持消息按钮（回调、跳转链接、指令按钮）。
- **看板功能**：支持设置用户看板、全员看板，可设置过期时间。
- **流式消息**：提供流式发送能力，可用于打字机效果。
- **智能 Markdown**：发送文本时自动检测 Markdown 特征，并以此格式发送；超长内容自动按段落/行分割。
- **消息编辑与撤回**：支持对已发送消息的修改和撤回操作。
- **批量发送**：支持一次性向多个接收者发送消息。

### 改进与优化
- 配置项全面更新：`ws_url`/`ws_token` 替换为 `bot_token`、`connection_mode` 及相关网络参数。
- 图片/文件/视频发送支持多种输入：本地路径、远程 URL、base64、data URL、云湖 key。
- WebSocket 自动重连采用指数退避策略，更加稳健。
- 新增 `send_by_session` 支持，适配器可被 AstrBot 内部 Agent 工具主动调用发送消息。
- 日志系统与 AstrBot 集成，所有模块统一使用 `logger`。

### 升级须知
- **配置不兼容**：从 1.x 升级到 2.0.0 必须重新配置插件。
- **无需任何外部 SDK**：升级后可以停止并卸载 `yunhubot-websdk`。
- 原有云湖机器人 Token 保持不变，需在云湖控制台中获取。
